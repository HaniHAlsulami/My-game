# اكتشف حالك في دقيقة

**طمّن نفسك وطمّنّا عليك 🙏**

لعبة تفاعلية قصيرة للفحص المبدئي للصحة النفسية. ترافق فيها الشخصية «طمّون» عبر أربع محطات (الشغف، المزاج، الهدوء، الأفكار)، وتجيب في كل محطة عن سؤال واحد من أداتي **PHQ-2** و**GAD-2**، ثم تظهر نتيجة الفحص ومسار التوجيه.

- **رابط اللعبة:** https://hanihalsulami.github.io/My-game/
- نقطة القطع: درجة 3 فأكثر في أي من الأداتين = فحص إيجابي يستدعي تقييماً أشمل.
- لا تُجمع أي بيانات شخصية، ولا تُحفظ الإجابات.
- هذا فحص مبدئي وليس تشخيصاً.
